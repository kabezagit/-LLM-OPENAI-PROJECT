# -LLM-OPENAI-PROJECT

LLM-OPENAI PROJECT (LangChain + Streamlit Chatbot)

Purpose
This app is an AI-powered chatbot built with LangChain, OpenAI, and Streamlit.
It lets users interact with a powerful language model (LLM) in a simple web interface, and demonstrates how to track and analyze LLM usage with LangSmith.

How It Works
User Interface:
The app uses Streamlit to create a web page where users can type questions.
Prompt Template:
The chatbot uses a system prompt to set its behavior and a user prompt to accept questions.
LLM Integration:
The app connects to OpenAI’s GPT model (e.g., gpt-4.1) using your API key.
LangSmith Tracking:
The app enables LangSmith tracking to monitor and analyze LLM interactions.
Response Generation:
When a user submits a question, the app sends it to the LLM and displays the answer

Features
Conversational AI chatbot using OpenAI’s GPT models.
Simple, interactive web UI with Streamlit.
Prompt engineering for chatbot personality.
LangSmith tracking for LLM analytics.
